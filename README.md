## What each weekly report covers

1. **Ads** — active creatives on Meta Ad Library and Google Ads Transparency Center, creative hooks/themes, formats, landing pages, and which ads look like they are **scaling** (long-running, many variants, high impressions).
2. **CAC** — estimated acquisition cost per paying customer, built from India edtech benchmark CPL/CPI numbers and each company's funnel shape. These are estimates unless a company publishes real numbers.
3. **Funnel** — the full acquisition path (ad → landing → trial/demo → paywall → paid), pricing, and any week-over-week changes.
4. **Traction** — funding, hiring, downloads, social following, claimed metrics.

## Known data-access limits

- `facebook.com/ads/library` and `adstransparency.google.com` are JavaScript apps that block server-side fetching (HTTP 403), so per-ad rows (library IDs, start dates, EU-style impression ranges) can't be scraped from this environment. Reports reconstruct creative strategy from social feeds, app-store pages, and third-party sources, and keep the Ad Library links above for a 2-minute manual check.
- Neither company publishes CAC; all CAC figures in reports are labelled estimates with the arithmetic shown.
